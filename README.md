# Competitor Search

Aplicación para monitoreo de noticias y campañas de empresas mediante Google News y futuras integraciones con redes sociales.

## Primera versión

- Google News RSS
- Búsqueda Empresa + Palabras
- Exportación CSV
- Exportación Excel

## Futuras versiones

- YouTube
- Facebook
- Instagram
- X
- TikTok
- IA para clasificación de campañas
